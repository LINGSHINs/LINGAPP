# 知一 · 运营学习空间

可部署到 GitHub Pages 的纯静态刷题网站。无需数据库、账户系统或 API 密钥。

## GitHub Pages 部署

1. 在 GitHub 创建一个仓库，上传本压缩包全部内容，保留 `dist` 与 `.github/workflows/pages.yml` 的目录结构。确保隐藏的 `.github` 文件夹也已上传。
2. 进入仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 进入 **Actions → Deploy Zhiyi to GitHub Pages → Run workflow**，等待完成。
4. 打开 Pages 显示的网站地址。所有资源使用相对路径，同时支持根域名和 `/仓库名/` 路径。

如果只想手动部署：将 `dist` 文件夹里的内容上传到仓库根目录，然后在 Pages 中选择从 `main / root` 分支部署。

部署为公开网站会使内置题库可被访问和下载，请根据你对这份题库的分享范围选择站点访问方式。

## 本地使用

需要通过 HTTP 服务打开，不能直接双击 `index.html`。例如在 `dist` 目录运行 `python -m http.server 8080`，然后在浏览器访问 `http://localhost:8080`。

## 题库与题号

- 2,957 题：单选 1,119，多选 863，判断 975。
- 8 个部门，包含必考题。
- 原始序号按部门从 1 重新开始；网站保留 `sourceId`，另设全库唯一 `id`。
- 选择部门后，范围默认使用部门内原题号；可以切换为全库统一编号。
- 不改变原文件题干、选项及答案。判断题将正确/错误统一映射为 A/B。
- 原文件没有解析，因此网站不编造解析。可以添加个人记忆笔记。

## 学习方式

顺序、随机、按部门、按题型、组卷考试、到期间隔复习、循环攻克、背题、闪卡、限时快答、三命闯关。答题卡支持跳题。

20 种彩蛋：60 秒冲刺、三命生存、十连击、错题首领、倒序旅行、部门接力、题型阶梯、盲选回忆、信心校准、排除大师、答案连线、番茄专注、每日盲盒、五题回声、知识马拉松、满分守护、骰子漫游、未见之地、深呼吸、遗忘修复。

## 记忆计划

固定间隔阶梯为 5 分钟、30 分钟、12 小时、1 天、3 天、7 天、15 天、30 天。首次答错或再次答错回到 5 分钟；首次答对进入 30 分钟。到期答对后才能推进下一阶段，完成第 8 阶段后标记为掌握并退出循环。提前作答只计次数，不会提前升级；提前答错仍会重新安排。

这是参考遗忘规律的固定间隔安排，并非对个人记忆的科学测量。没有后台推送；打开网站后检查到期题。

## 数据与跨设备

- 题目记录、正确率、错题、收藏、笔记、学习热力图、设置保存在当前浏览器 `localStorage`。
- 正在进行的练习会单独保存，可从“开始刷题”继续；开始新练习会替换当前练习。
- 不自动在不同设备同步。通过设置里的 JSON 导出与导入迁移；导入是替换，不是合并。
- 自定义字体保存在 IndexedDB，不包含在学习备份中；切换设备需要重新上传。
- 清除浏览器数据会删除进度，请定期备份。
- 在有网络时完整打开一次，Service Worker 缓存成功后支持离线使用。安装能力取决于浏览器和站点托管环境。

## 主题、字体和声音

56 套主题，独立阅读底色，12 类主题粒子，粒子速度/旋转/配色随主题变化，标志与图标线形同步变化。品牌及作品名称仅表达视觉灵感，非官方联名。

内置 Noto Sans SC 与 Noto Serif SC 的题库字形子集，随站点加载，无外部字体网络依赖。题库以外的缺字由设备字体回退。字体遵循 SIL OFL，详见 `dist/fonts`。支持本地上传中文字体。

自定义背景、强调色、阅读底色、亮度与光晕；低对比强调色会自动调整以保障阅读。默认关闭粒子和声音，尊重系统减少动态效果设置。

答对与答错音效各有 5 种，通过 Web Audio 合成，无音频下载，首次用户触控后启用。

## 更新站点
